## Reglas generales

- El Documento de Análisis Funcional es la referencia principal.
- Inscripción y matrícula son procesos diferentes.
- No se deben eliminar registros históricos académicos.
- El sistema debe aplicar control de acceso mediante roles y permisos.
- Las modificaciones de base de datos deberán realizarse mediante migraciones.
- No utilizar migrate:fresh cuando el sistema contenga información real.
